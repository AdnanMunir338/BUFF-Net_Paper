# BUFF-Net project page — GitHub Pages

A minimal, responsive static project website for:

**BUFF-Net: Boundary–Uncertainty Guided Multi-Scale Refinement Network with Frozen Forensic Priors for Image Manipulation Detection and Localization**

Authors: Adnan Munir, Souad Mohaoui, Shizhen Chang*  
Affiliation: Information Coding Division, Department of Electrical Engineering, Linköping University, Sweden  
Conference: WACV 2027

## Files

- `index.html` — page content
- `assets/style.css` — responsive styling
- `assets/script.js` — BibTeX copy button
- `assets/favicon.svg` — site icon
- `images/teaser.svg`, `images/method.svg`, `images/results.svg` — clearly labeled illustrative placeholders

## Before publishing

1. Replace the draft abstract and method/results placeholder text in `index.html` with verified manuscript content.
2. Replace the three illustrative SVG files with your actual figures, or update the image paths in `index.html`.
3. Add your resources:
   - `assets/paper.pdf`
   - `assets/poster.pdf`
   - Update the Video link to your talk/video URL.
   - Update the Code link to your repository URL.
4. Confirm the final BibTeX against the official publication details. The current BibTeX is a template, not a verified record.

The Paper and Poster buttons point to the paths above. Add the files with exactly those names or change the links.

## Deploy on GitHub Pages

1. Create a **public** repository on GitHub, e.g. `buff-net`.
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment to complete. Your site URL will usually be:
   `https://YOUR-USERNAME.github.io/buff-net/`

If the repository is named `YOUR-USERNAME.github.io`, the site will instead be available at the root URL:
`https://YOUR-USERNAME.github.io/`
